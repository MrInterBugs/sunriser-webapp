# Application screenshots

Actual captures of the current Living Aquascape application with colour themes (source
`8ddb57c`), rendered on 9 November 2026 with Chromium 156. Metadata, state and selected
saved settings were read from `http://192.168.0.13` on 24 October 2026 (10:46–10:48 UTC),
which reported **SunRiser10, firmware 1.007**. The photographs are reference aquariums,
not live views.

Controller reads were serialized with at least five seconds between requests.
No configuration changes or output commands were sent. The application was served
locally from recorded read responses; these captures made **no controller requests**.
The current interface groups some saved-setting reads differently, so five read
responses were assembled from values recorded in separate reads of the same session;
no value was invented. State readback is fixed at **12:47:01 device-local time**.
These are locally rendered views of captured readback, not a live monitoring
session or physical-output validation.

Desktop captures use a 1440×1000 viewport and include the full page. Mobile
captures use a 390×844 viewport; Schedules is scrolled to the curve and point editor.
Fonts, images and settings have finished loading. WebP compression keeps these
images small without adding runtime assets to the application.
